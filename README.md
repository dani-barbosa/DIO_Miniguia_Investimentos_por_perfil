# DIO_Miniguia_Investimentos_por_perfil_NotebookLM
Trata-se de um projeto de utilização do NotebookLM para criar um especialista em investidores iniciantes com linguagem simples e bastante didática.
 
Objetivos: 
  1. Oferecer noções de investimento para novos potenciais investidores de forma simples e clara
  2. Exemplificar a importância da mudança de mentalidade através de hábitos simples, paciência e disciplina emocional
  3. Indicar as melhores estratégias para o investidor iniciante
