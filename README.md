# DIO_Miniguia_Investimentos_por_perfil_NotebookLM
Trata-se de um projeto de utilização do NotebookLM para criar um documento especializado no tema de investimentos por perfil de investidor
 
Objetivos: 
  1. Oferecer noções de investimento para novos potenciais investidores de forma simples e clara
  2. Exemplificar os tipos de investimentos disponíveis para iniciantes
  3. Indicar as melhores estratégias por perfil de investidor
